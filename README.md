# Web Kon Tum

Website giới thiệu địa điểm du lịch, văn hóa, ẩm thực, đặc sản và quà tặng Kon Tum.

## Công nghệ

- Next.js, ReactJS, TypeScript, JavaScript
- HTML5, CSS3
- Node.js API Routes
- REST API
- MongoDB

## Chức năng chính

- Xem danh sách nội dung theo danh mục: Địa điểm, Văn hóa, Ẩm thực, Đặc sản, Quà tặng.
- Xem chi tiết từng nội dung/sản phẩm.
- Thêm sản phẩm vào giỏ hàng với các mục có thể mua.
- Đăng nhập/đăng ký và phân quyền admin cơ bản.
- Quản lý sản phẩm, danh mục bằng trang admin.

